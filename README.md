# Python + MySQL Console Board

Python과 MySQL을 연동하여 구현한 콘솔 기반 게시판 프로젝트입니다.

회원가입과 로그인 기능을 기반으로 게시글과 댓글을 관리할 수 있으며,
로그인한 사용자에 따라 기능과 권한을 구분하도록 구현했습니다.

## 주요 기능

- 회원가입
- 아이디 중복 확인
- 로그인 / 로그아웃
- 게시글 작성
- 게시글 목록 조회
- 게시글 상세 조회
- 댓글 작성
- 본인 게시글 삭제
- 게시글 삭제 시 댓글 자동 삭제

## 프로젝트 구조

### userTable

회원 정보를 저장합니다.

### boardTable

게시글 정보를 저장합니다.

### commentTable

게시글에 작성된 댓글 정보를 저장합니다.

회원, 게시글, 댓글 데이터를 서로 연결하여 관리하도록 구성했습니다.

## 주요 구현 내용

- 로그인한 사용자 정보를 기준으로 게시판 기능 사용
- 게시글과 댓글 작성 시 현재 로그인한 사용자 정보 사용
- 게시글 존재 여부 확인 후 상세 조회 및 댓글 작성
- 게시글 작성자 확인 후 본인 글만 삭제 가능
- 게시글 삭제 시 해당 게시글의 댓글도 함께 삭제
- DB 비밀번호는 `.env` 파일로 분리하여 관리

## 사용 기술

- Python
- MySQL
